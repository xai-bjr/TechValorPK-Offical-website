# TechValorPK Official Website

Professional static HTML5 portfolio website for TechValorPK.

## Built with
- Semantic HTML5
- CSS3 with 3D transforms/perspective
- Vanilla JavaScript
- Canvas particle field
- Responsive design
- No framework and no server required

## GitHub Pages
Create a GitHub repository such as `techvalorpK.github.io` if that matches the GitHub username.
Upload the repository contents to the root.
Go to **Settings → Pages → Deploy from branch → main → /(root)**.
Save and wait for the Pages deployment.
